# Security

Report a suspected security issue privately to the repository owner or the Ogilvy security contact. Do not open a public issue containing credentials, personal data, client data, exploit details, or production identifiers.

Include the affected package and file, the smallest safe reproduction, the impact, and whether the issue is local, staging or hosted. Redact tokens and payloads before sharing. Do not test against production or paid vendor endpoints without explicit written authorization.

This repository is internal WPP work. Keep secrets in the approved local or hosted secret store. Never commit `.env` files, service account keys, passcodes, API tokens or customer data.
