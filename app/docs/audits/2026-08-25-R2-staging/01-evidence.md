# 42 full-route design evidence

## Structural evidence

The frontend contains 130 static interactive tag occurrences across the 15 route-owner modules: 91 buttons, 30 links, 8 inputs, and 1 select. It repeats 12 `PageHero` instances, 8 `EmptyState` instances, 70 identical `1px solid var(--line)` surface borders, 17 pill-radius patterns, and 14 divider-rule patterns.

Today contains three overlapping topic rankings: direction lists, Emerging cards, and the full board. Explore renders the same `BrowsePage` used by Browse. Three Ask or retrieval entry points remain across Today, Explore or Browse, and Console.

Visible engine internals include signal index, seed score, graph score, signal quality, dataset, `seed_graph`, `seed_candidates`, and “AI clusters.” Hardcoded user material includes 13 prompts or suggestion chips, 25 legacy topic mappings, and 19 glossary definitions.

## Visual evidence

The full frontend contains 37 fixed font sizes and 22 distinct clamp expressions. Today plus shared UI uses 29 spacing values from 1 to 90 pixels. Radius use extends beyond the declared 8, 12, 18, and 26 pixel scale to 5, 6, 7, 9, 10, 11, 13, 99, 999, and circular values.

The theme declares 55 primitive color values. Status is implemented twice: uppercase mono rectangles and sentence-case sans pills. Nine visible card families appear on Today. Four chart families appear, but interpretation is separated from the ranked signals.

Desktop Today is 3,641 pixels tall. Mobile Today is 6,778 pixels tall. The recommendation falls below board, markets, channel mix, and sentiment on mobile. Some mobile labels are 8 to 8.5 pixels.

The Emerging screenshot repeats status, a three-decimal index phrase, title, summed engagement, mentions, and the 30-day window on three visually identical cards. The raw index text wraps while a large empty column and lower band remain unused. Each card repeats `30d` twice and provides no history, confidence, source breadth, explanation, or action.

## Usefulness and honesty evidence

Today repeats existing tracked categories under “Emerging this week.” It does not prove discovery provenance, a change driver, historical comparison, or evidence coverage.

Compare chooses a winner from the larger raw number. It does not ask for the strategist's objective or compare audience fit, risk, proof quality, or source mix.

Build still promises Brand24 and “AI Mode hero activations.” Topics still says “AI clusters,” retains Brand24 setup copy, and treats Gen Z as the served core without naming a demographic source.

Listen filters only the rows already loaded. Sentiment percentages cover the loaded slice. Source, date, deduplication, and geo-confidence controls are absent.

Seeds hard-locks output to Gen Z, Nano Banana, and Lyria. Discover exposes graph score, dataset names, internal table names, CLI approval, and Copy ID. Network says an edge is a real post connection, but the code creates it from top-voice membership. Lexicon definitions come from a static 19-entry glossary.

Method states eight sources in one section and includes retired Brand24 in another. It does not show the live SocialCrawl surface inventory, last success, yield, credit use, product boundaries, legacy bias, or demographic method.
