Clear space and minimum size

Keep clear space equal to the height of the "P" in the wordmark on all sides. Do not crowd the mark with other elements inside that zone.

Minimum size: 120px wide for the full lockup, 24px for the icon mark alone.

Usage

Ink is the primary dark. Signal Green is the pulse accent, used sparingly for the waveform and live-signal states. Amber marks a single highlighted data point, never body copy. Slate is secondary text. White is base canvas on dark layouts.

Typography

Wordmark: Segoe UI Bold, tracked +2. Tagline: Segoe UI Semibold, tracked +5, all caps.

Body copy in product and email: Segoe UI Regular / Semibold, 14 to 16px. Fallback stack: Segoe UI, Source Sans 3, Arial, sans-serif.

Do and don't

Do

  • Use the dark lockup on dark backgrounds only
  • Keep the green waveform as the only accent stroke
  • Scale the lockup proportionally

Don't

  • Recolor the icon circle
  • Stretch or skew the mark
  • Place the light lockup on a busy photo background
  • Add a drop shadow or outline to the wordmark
